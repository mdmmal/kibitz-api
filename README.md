# Kibitz API

 Kibitz-API is a backup server built with Node and Express that is written by hand to save chess games from the Kibitz app.

## How I build this
- I must write every line I commit
- AI teaches concepts, provides additional learning resource, gives hints on errors and reviews code after I write it
- No Claude Code on this repo and Copilot and autocomplete stay off
- Stuck past 30 minutes means ask for a hint, never the answer
